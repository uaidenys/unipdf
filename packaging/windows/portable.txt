UniPDF portable mode

While this file sits next to pdfcraft.exe, UniPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the UniPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move UniPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\UniPDF and
%LOCALAPPDATA%\UniPDF) instead. If UniPDFData can't be written (for example on a read-only
drive), UniPDF says so and uses the per-user folders instead.
